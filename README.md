# B站动态时间线导航

一个 Tampermonkey 用户脚本，通过 B 站官方 API 抓取 UP 主全部动态，缓存在本地 IndexedDB，并支持在动态详情页按时间顺序连续翻阅。

## 功能

- **断点续传全量抓取**：从最新一路翻到最早；中途停止、关页、断网都不会丢进度，下次点「继续全量」从断点接着抓
- **抓取最新（增量）**：从最新开始翻，遇到已缓存动态即停，只补新增内容
- **本地缓存**：IndexedDB 按 UP 主 UID 隔离存储，刷新页面不丢数据
- **点击跳转**：列表点击任意动态直达详情页
- **连续翻阅**：详情页用「◀ 上一条 / 下一条 ▶」按时间顺序浏览，无需返回列表
- **停止即保存**：抓取中可随时停止，进度与已抓数据均已落盘
- **风控与容错**：HTTP 412 单独识别；请求失败指数退避重试（最多 3 次）；空页最多容忍 5 次再判定结束；抓取量超过 500 条后自动加大请求间隔
- **内容摘要**：自动识别视频 / 专栏 / 图文 / 新版 Opus / 转发 / 纯文字，生成简短标签
- **清空缓存**：一键清空当前 UP 主的缓存、抓取进度与导航会话

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 新建脚本，粘贴本文件内容并保存
3. 打开任意 UP 主空间页：`https://space.bilibili.com/数字UID`

## 使用

1. 点击右下角 📅 悬浮球打开面板
2. 首次使用点 **全量抓取**；中断后再进入页面，按钮会变为 **继续全量**，点击即从断点续抓
3. 抓完后按钮变为 **重新全量**；日常更新用 **抓取最新**
4. 抓取过程中可点 **⏸ 停止**，进度自动保存
5. 抓取完成后，点击列表条目或使用 **◀ 上一条 / 下一条 ▶** 浏览
6. 需要重建缓存时点 **清空**（二次确认，不可撤销）

## 说明

- 依赖 B 站网页版登录态（Cookie）
- 数据接口：`api.bilibili.com/x/polymer/web-dynamic/v1/feed/space`（带 `features=itemOpusStyle`，兼容新版图文）
- **数据存放**：
  - 动态数据 → IndexedDB `BiliDynamicCache`（`space.bilibili.com` 源下，按 `host_mid` 索引）
  - 抓取进度 → `GM_setValue('bili_progress_<mid>')`，记录 `offset`、`is_completed`、`count`
  - 详情页导航会话 → `GM_setValue('bili_nav_session')`
- **详情页依赖会话**：`t.bilibili.com` 页面无法直接读空间页的 IndexedDB，导航列表来自会话快照；会话缺失时会提示回空间页重新开始
- 全量抓取条数多时耗时较长，建议先抓一段再继续；连续抓取可能触发临时风控，脚本会自动退避重试
- 仅在空间页与 `t.bilibili.com` 动态详情页生效
