# B站动态时间线导航

一个 Tampermonkey 用户脚本，通过 B 站官方 API 抓取 UP 主全部动态，缓存在本地 IndexedDB，并在动态详情页提供按时间顺序的连续翻阅。

## 功能

- **全量抓取**：从最新动态一路翻页到最早一条，写入 IndexedDB
- **增量更新**：从最新开始翻，遇到已缓存动态即停，只补充新增内容
- **本地缓存**：IndexedDB 按 UP 主 UID 隔离，刷新或重开页面不丢数据
- **点击跳转**：列表点击任意动态，直接跳转到对应详情页
- **连续翻阅**：详情页中通过「◀ 上一条 / 下一条 ▶」按时间顺序浏览，无需返回列表
- **可停止 / 自动重试**：抓取过程可随时停止；网络波动时自动重试（最多 3 次）
- **内容摘要**：自动识别视频、专栏、图文、直播、番剧、转发、纯文字等类型并生成简短标签
- **清空缓存**：一键清空当前 UP 主的全部本地缓存与会话

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 新建脚本，粘贴本文件内容并保存
3. 打开任意 UP 主空间页：`https://space.bilibili.com/数字UID`

## 使用

1. 点击右下角 📅 悬浮球打开面板
2. 在空间页点击 **全量抓取** 建立初始缓存（首次必须）；之后日常用 **增量更新**
3. 抓取完成后，点击列表条目或使用 **◀ 上一条 / 下一条 ▶** 浏览
4. 需要重建缓存时点 **清空缓存**（会二次确认，不可撤销）

## 说明

- 依赖 B 站网页版登录态（Cookie）
- 数据来源：`api.bilibili.com/x/polymer/web-dynamic/v1/feed/space`
- 抓取请求带随机延时（约 1.2–1.7s），连续抓取可能触发临时风控，脚本会自动重试
- **缓存位置**：IndexedDB 存储于 `space.bilibili.com` 源下，按 `host_mid` 索引
- **详情页导航**：依赖 `GM_setValue` 保存的会话（当前 UP 主 UID + 列表快照 + 当前索引）；若会话缺失，详情页会提示回空间页重新开始
- 全量抓取条数较多时耗时较长，建议分批或先增量更新
- 仅在空间页与 `t.bilibili.com` 动态详情页生效
